# Assets Directory

This directory should contain the following image assets for the app:

- `icon.png` - App icon (1024x1024px recommended)
- `splash.png` - Splash screen image
- `adaptive-icon.png` - Android adaptive icon
- `favicon.png` - Web favicon

For now, you can use placeholder images or create simple colored images. The app will work without these, but they're referenced in `app.json`.

To generate placeholder assets, you can use online tools or create simple colored squares with the app name/logo.
